What it does

Seven pipeline phases, fully resumable, exportable to CSV / Excel / SQLite.

🔍

Universal discovery

Crawls listing/directory sites and follows pagination, infinite scroll and SPAs to find every profile page — no selectors to write.

✉️

Contact extraction

Emails, phones, social profiles, contact forms — validated, deduped and normalized (phones to E.164, MX-ready emails).

🧠

AI-powered extraction

Any free-text goal via Google Gemini — "extract pricing tiers", "find job openings" — alongside images, articles and product data.

🛡️

Anti-blocking

Smart headless-Chromium fallback for anti-bot sites, cookie-banner dismissal, login walls, session persistence and custom JS interactions.

🖥️

Web dashboard

A no-code local UI: paste seed URLs, tick what to extract, watch live progress, filter results and download the dataset.

♻️

Resumable & polite

Checkpointed to SQLite so interrupted runs resume. Respects robots.txt and rate-limits per domain by default.

Setup

Python 3.10+. Takes about a minute.

Clone & install

Grab the repo and install dependencies.

git clone https://github.com/noor202401938-netizen/crawler
cd crawler
pip install -r requirements.txt
playwright install chromium  # for JS-rendering fallback

Configure (optional)

Copy the example env file, or set variables at runtime. Add GEMINI_API_KEY only if you want AI extraction.

cp .env.example .env  # edit as needed

Add your seed URLs

Put one directory/listing URL per line in links.txt (or point SEED_FILE at your own).

Usage

Run it from the browser, or from the command line.

🖥️ Web dashboard

No flags — start crawls, watch live progress, download results.

pip install flask
python webapp.py

Then open http://127.0.0.1:5000 and:

  1. Paste seed URLs (one per line)
  2. Tick what to extract
  3. Hit Start crawl, watch the status pill
  4. Filter & download CSV / Excel when done

⌨️ Command line

Scriptable and CI-friendly.

# default run
python main.py

# choose extraction targets
python main.py --extract emails,phones

# AI extraction (needs GEMINI_API_KEY)
python main.py --custom-prompt \
  "extract pricing tables"

# override config via env vars
SEED_FILE=links.txt CONCURRENCY=8 \
  python main.py --extract emails,images

Extraction targets

TargetWhat you get
